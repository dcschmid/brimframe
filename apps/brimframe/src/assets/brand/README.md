# BrimFrame brand artwork

`wordmark.svg` is a clean geometric interpretation of the owner-supplied
“Futuristisches BRIMFRAME-Studiologo.png” reference. Its letter outlines read
**B R I M F R A M E**, with an intentionally legible F. This is an editable
implementation asset rather than an automated bitmap trace or an approved final
master logo. `BrimFrameWordmark.astro` adds the readable HTML descriptor and
accessible text fallback. Replace the SVG when a final master is available.

`hero-frame.svg` interprets “brimframe-hero-teaser-reference.png” as static
architecture: a B-shaped outer frame, inset F, dark extruded surfaces, edge
lighting and a grounded perspective. CSS supplies responsive composition and
subtle ambient light. Both references remain source direction, not screenshots
embedded in the website. There is no essential copy in the hero SVG.

The supplied official Riff Racers logo is a separate production asset and is
preserved unchanged under `../games/riff-racers/`.
